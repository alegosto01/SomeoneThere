# SomeoneThere Roadmap

## Now: Remote Viewing Visit pilot

Goal: prove that people moving to Madrid value a trusted local verifier attending a rental viewing while they join by video call.

1. Define the Remote Viewing Visit service.
2. Create remote-viewing checklist.
3. Create verifier safety SOP.
4. Name backup helper/admin.
5. Recruit 1 trusted verifier/helper.
6. Run 3 dry runs.
7. Create landing page.
8. Run 3-5 pilot visits.

## Next: simple request workflow

Only after pilot evidence:

- simple request form
- manual admin assignment
- tracked email delivery
- basic internal status tracking
- short verification report generation

## Later: operations and payments

Only after paid demand is shown:

- payments
- scheduling
- more verifiers
- verifier onboarding
- QA workflow
- retention automation

## Later add-ons

These are not the MVP core:

- duplicate-image search
- digital-only scam analysis
- landlord background checks
- ownership verification
- AI risk scoring
- contract review
- price analysis
