# User Stories

## Tenant / customer

- As a student moving to Madrid, I want someone local to check a room before I send a deposit.
- As an expat, I want to know whether the apartment in the listing actually exists.
- As a parent, I want reassurance before my child pays for accommodation abroad.
- As a tenant, I want a simple report that tells me whether the listing looks safe or suspicious.
- As a user, I want photos/videos from the verifier so I can trust the result.
- As a user, I want the verifier to ask basic questions to the landlord or agent.
- As a user, I want a fast answer because rental listings disappear quickly.

## Verifier

- As a local verifier, I want clear instructions for each check.
- As a verifier, I want to know the exact address, time, and scope before accepting.
- As a verifier, I want a simple checklist to follow during the visit.
- As a verifier, I want to upload evidence easily from my phone.
- As a verifier, I want to be paid quickly after the report is accepted.

## Admin / operator

- As an admin, I want to see new verification requests.
- As an admin, I want to assign a verifier manually.
- As an admin, I want to review the report before sending it to the user.
- As an admin, I want to track request status.
- As an admin, I want to collect repeated red flags to improve the product.
