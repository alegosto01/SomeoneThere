# Remote Viewing Pilot Plan

## Pilot objective

Prove whether people moving to Madrid will use a SomeoneThere verifier to view a rental remotely by video call before sending a deposit.

## First milestone

3-5 people moving to Madrid use a SomeoneThere verifier to view a rental remotely by video call and say the service helped them decide whether to continue.

## Sequence

1. Define the Remote Viewing Visit service.
2. Create remote-viewing checklist.
3. Create verifier safety SOP.
4. Name backup helper/admin.
5. Recruit 1 trusted verifier/helper.
6. Run 3 dry runs.
7. Create landing page.
8. Run 3-5 pilot visits.
9. Build simple request software only after pilot evidence.
10. Add payments, scheduling, and more verifiers later.

## Dry runs

Run 3 unpaid dry runs before offering paid pilots:

- One with Alessandro acting as client.
- One with a trusted friend acting as client.
- One with a realistic listing and full checklist.

Measure:

- coordination time
- travel time
- call quality
- viewing duration
- checklist completeness
- post-visit summary time
- safety or permission issues

## Pilot users

Recruit manually from:

- Madrid relocation communities
- Erasmus and international student groups
- expat groups
- personal network referrals
- parents helping students move

Do not run paid ads until the manual offer converts at least a few qualified prospects.

## Success criteria

- 3-5 completed Remote Viewing Visits.
- At least 3 clients say the service helped them decide whether to continue.
- No verifier safety incident or near-miss.
- No visit requires SomeoneThere to negotiate, pay, sign, collect keys, or give legal advice.
- Manual operating time is clear enough to set a realistic price.

## What not to validate yet

- AI risk scoring
- duplicate-image search
- landlord background checks
- ownership verification
- contract review
- automated scheduling
- marketplace matching
- multi-verifier operations
