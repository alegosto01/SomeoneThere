# Phase 1 GitHub Issues

Create these as GitHub issues once the repository is ready.

## Market validation

### 1. Complete competitor research matrix

Research direct, substitute, adjacent, and Madrid-local competitors. Fill the competitor matrix with status, funding, traffic, reviews, adoption evidence, and lessons.

Labels: `research`, `market-validation`

### 2. Interview 10 target users

Interview international students, Erasmus students, expats, and remote workers moving to Madrid. Validate whether they have experienced fear of scams and whether they would pay for verification.

Labels: `research`, `customer-discovery`

### 3. Test willingness to pay

Create three package descriptions and ask users which they would pay for. Track price sensitivity.

Labels: `business`, `pricing`

## Product

### 4. Create landing page copy

Labels: `product`, `copywriting`

### 5. Build intake form

Labels: `product`, `mvp`

### 6. Create verification report template

Labels: `operations`, `product`
